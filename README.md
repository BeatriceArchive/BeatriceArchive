## 📜 禁书库守则

| | 守则 | 意思是 |
| :-: | --- | --- |
| 壹 | **稳定优先** | 成熟的书进入维护模式，不为“多功能”堆复杂度 |
| 贰 | **最小权限** | 能不 MITM 就不 MITM，能不碰的设置就不碰 |
| 叁 | **实机为准** | 每次改动都要真机上的表现作证，不靠猜 |
| 肆 | **公开边界** | 节点、订阅、Cookie 与任何凭据永远不进书库，CI 替贝蒂守门 |
