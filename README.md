## 📜 禁书库守则

1. **稳定优先** —— 成熟的书进入维护模式，不为“多功能”堆复杂度
2. **最小权限** —— 能不 MITM 就不 MITM，能不碰的设置就不碰
3. **实机为准** —— 每次改动都要真机上的表现作证，不靠猜
4. **公开边界** —— 节点、订阅地址、Cookie、任何凭据，永远不进书库；CI 替贝蒂守着门
