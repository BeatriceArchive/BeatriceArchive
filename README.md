这里是贝蒂的禁书库。平时窝在书架之间整理 **Surge iOS** 的模块和配置，把乱七八糟的规则一本本归好位；闲下来就看动画、啃轻小说。至于哪部最好看——Re:ゼロ，这还用问吗。

## 📚 开放书架

| 藏书 | 内容 | 适合谁 |
| --- | --- | --- |
| **[Beatrice-Surge-Modules](https://github.com/BeatriceArchive/Beatrice-Surge-Modules)** | 系统网络基线、单一基础面板、Bilibili 每日任务与官方二维码登录 | 想直接装模块、少折腾的人 |
| **[Beatrice-Surge-Config](https://github.com/BeatriceArchive/Beatrice-Surge-Config)** | 公开 Profile 模板：`[General]`、策略组与路由规则，带外部规则漂移审计 | 想要一份干净基线、自己接节点的人 |

> 模板**不含任何代理节点**。先接入你自己的 `[Proxy]`，再按需调整策略组。

## 📜 借阅守则

- **稳定优先** —— 成熟的东西进入维护模式，不为“多功能”堆复杂度
- **最小权限** —— 能不 MITM 就不 MITM，能不改的设置就不碰
- **实机为准** —— 改动以真实设备上的表现为证据，不靠猜
- **公开边界** —— 仓库里永远没有节点、订阅地址、Cookie 或任何凭据；CI 会替贝蒂盯着

## 🔖 借书前先看这里

- 用法和每个模块的参数，写在各自仓库的 README 和 `docs/` 里
- 遇到问题请开 issue，附上 Surge 版本、模块版本和日志片段，贝蒂才好帮你翻书
- 觉得好用的话，点个 ⭐ —— 贝蒂才不是在期待呢……大概
